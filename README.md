# Nova AI — 17 Specialized AI Agents

Nova AI is an autonomous multi-agent system that orchestrates 17 specialized AI agents to complete any business task.

## Agents
Business, Marketing, Sales, Finance, Technology, Content, Productivity, Research, Analytics, Coding, Document, Automation, SEO, Social Media, Customer Support, Strategy, QA/Verification

## Deploy to Vercel
1. Fork this repo
2. Connect to Vercel
3. Deploy (no env vars needed for basic usage)

## Optional: Connect External LLM
Add to `.env`:
```
VITE_NOVA_LLM_API_KEY=your_key
VITE_NOVA_LLM_MODEL=gpt-4o
```
